🛠️ Technologies Used in the Project
🧠 Llama 3.2 (8B, 8192 context) — Open-source LLM used via Groq.

⚡ Groq Cloud — Ultra-low latency inference backend for Llama models.

🧱 LangChain — Handles prompt templates, chains, and model invocation.

📺 Streamlit — UI framework for building the front-end interface.

🐍 Python — Core language tying everything together.

🔐 dotenv / os — For managing environment variables like GROQ_API_KEY.
